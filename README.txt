CIRCLESNAP
==========
Watches your screen and clicks a circle every time it pops up, so you can AFK.
By default it looks for the purple "x2" circle. You can teach it any other
circle (other games too) with "Learn target".

It runs as its own window next to the game: it only looks at the screen and
moves/clicks the mouse. It does NOT inject anything into the game or touch
its files. Works on Windows 10/11, nothing to install.


START
-----
1. Unzip the folder first (right-click the zip > Extract All).
2. Double-click "Start CircleSnap.bat".
   If Windows says "Windows protected your PC": More info > Run anyway.
3. Drag the window to the side so it doesn't cover the game.
4. Press START (or F9).


BUTTONS
-------
START / STOP      On / off. F9 works too, even inside the game.
Learn target      Teach it a circle: press it, then hover your cursor over the
                  circle and hold still for 3 seconds. From then on it only
                  clicks circles that look like that one.
Test              Looks once without clicking and shows a red box around
                  what it found.
Reset             Go back to the built-in purple x2.
Delay after click Seconds to wait after a click before looking again.
Human movement    Moves the mouse in a curve with natural speed instead of
                  gliding straight to the circle.
Always on top     Keeps the window above the game.
Update now        A yellow banner shows up when a new version is out. Click
                  Update now and the app updates itself and restarts.
Update log tab    What changed in each version.


TIPS
----
- Don't cover the circle with this window.
- Turn off sleep / screen lock while AFK.
- Logs show every click with the time.
