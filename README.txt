CIRCLETRACK
==========
Watches your screen and clicks a circle every time it pops up, so you can AFK.
By default it looks for the purple "x2" circle. You can teach it any other
circle (other games too) with "Learn target".

It runs as its own window next to the game: it only looks at the screen and
moves/clicks the mouse. It does NOT inject anything into the game or touch
its files. Works on Windows 10/11, nothing to install.


START
-----
1. Unzip the folder first (right-click the zip > Extract All).
2. Double-click "Start CircleTrack.bat".
   If Windows says "Windows protected your PC": More info > Run anyway.
3. Drag the window to the side so it doesn't cover the game.
4. Press START (or F9). F10 stops.


TABS
----
Clicker       STATUS, START, MODULE (pick the clicking engine) and logs.
Settings      Keybinds (Start / Turn off), the target (Learn target, Test,
              Reset), delay after click, Human movement, Always on top.
              Hover the ? next to any setting to see what it does.
Update log    What changed in each version.
Other         More coming soon.

When a new version is out, a yellow "Update available" banner pops up
while the app is open. Click Update now and it updates and restarts.
Updates are signed: the app only installs updates from the developer.
If your copy was changed by someone, the sidebar says "Modified copy"
and Repair puts the official files back.

TIPS
----
- Don't cover the circle with this window.
- Turn off sleep / screen lock while AFK.
- Logs show every click with the time.
