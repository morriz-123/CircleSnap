# CircleTrack

Clicks the purple **x2** circle (or any circle you teach it) every time it pops up, so you can AFK.

## [Download CircleTrack](https://github.com/morriz-123/CircleSnap/archive/refs/heads/main.zip)

1. Click **Download CircleTrack** above, then unzip it (right-click > Extract All).
2. Double-click **Start CircleTrack.bat**. If Windows says "Windows protected your PC": More info > Run anyway.
3. Press **START** (or F9).

Updates install themselves: when a new version is out, the app shows an **Update available** banner.

Current version: **v1.4.0**. See [changelog.txt](changelog.txt) for what's new.
